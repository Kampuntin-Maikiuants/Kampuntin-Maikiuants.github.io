# Kampuntin Maikiuants – página web

Código de la página web de **Kampuntin**, la organización de turismo comunitario de la comunidad shuar de Maikiuants (Amazonía ecuatoriana): tours, voluntariado, ciencia comunitaria y novedades, en español, inglés y francés.

- Página web: https://www.kampuntin.org
- Contacto: ocstkampuntin@gmail.com

La página se construye con Jekyll y se publica sola con GitHub Pages cada vez que se guarda un cambio.

El manual para actualizar la página (tours, galería, novedades, equipo, dominio) no está en GitHub porque contiene datos de acceso. Pídelo al equipo de Kampuntin.
